## Featured Research Highlights

### Machine Learning-Based Wind Speed Bias Correction

Developed an end-to-end machine learning workflow to improve wind speed estimates by learning the relationship between ERA5 and CERRA reanalysis datasets.

- Integrated atmospheric reanalysis data with terrain and geographical features.
- Compared Linear Regression, Random Forest, XGBoost, and quantile-mapping baselines.
- Applied temporal validation to assess predictive performance.
- Achieved a test RMSE of approximately **0.90 m/s**, representing a **37.4% reduction** compared with the original bilinear interpolation baseline.

**Key technologies:** Python, XGBoost, Scikit-learn, Xarray, Rasterio

### Deep Learning for CO₂ Geological Storage Prediction

Contributed to a collaborative deep learning project investigating surrogate models for subsurface CO₂ storage simulations.

- Explored neural network approaches including ResUNet and Fourier Neural Operators.
- Modelled spatial and temporal variations in reservoir pressure and CO₂ saturation.
- Evaluated predictions across 24 simulation time steps.
- Achieved an R² of **0.974 for pressure** and **0.958 for CO₂ saturation** using ResUNet.

**Key technologies:** Python, PyTorch, ResUNet, FNO
